# Jhunlea Photography & Printing System
# Project Scope


## Project Name

Jhunlea Photography & Printing System


## System Purpose

The system aims to organize and improve the daily operations of Jhunlea Photography and Printing Station.

It will replace manual handling of customer requests, printing orders, photography bookings, and records with a centralized web-based system.


## Main Objectives

The system aims to:

Manage customer printing requests
Manage photography booking requests
Allow customers to submit required files
Allow owner to review and update requests
Track request progress
Maintain organized customer and transaction records
Record walk-in customers and their in-person printing orders, bookings and payments
Show the daily transactions and the total income of the business


# System Users


## Print Shop Owner

The owner can:

View customer requests
Review uploaded files
Manage printing services
Manage photography packages
Update request status
Confirm schedules
Record face-to-face payments
Record walk-in orders and bookings
View daily transactions and income reports
View order history


## Customer

Customers can:

Register an account
Login
Submit printing requests
Upload files
Book photography services
View request status
View previous requests


# Core Modules


## 1. Authentication Module

Handles:

Registration
Login
Logout
User roles


## 2. Customer Module

Handles:

Customer profile
Printing requests
Photography bookings
Request tracking


## 3. Printing Management Module

Handles:

Printing services
File uploads
Printing specifications
Order status


## 4. Photography Module

Handles:

Photography packages
Themes
Scheduling
Booking requests


## 5. Payment Recording Module

Handles:

Payment records
Paid amount
Remaining balance
Walk-in transactions
Payments logbook
Income reports

Payments are recorded face-to-face only.


# System Limitations

The system will not include:

Online payment gateway
E-wallet integration
Automatic online payment confirmation


# Development Scope

Initial development focuses on creating a functional management system for Jhunlea Photography and Printing Station.
